# Hotel Rajmahal by Vilasa Group — Official Website

A production hospitality website for **Hotel Rajmahal by Vilasa Group**, situated at Nathuwas Circle, Nathuwas, Nathdwara, Rajasthan – 313301.

## Tech Stack

- **React 19** + **TypeScript** + **Vite 6**
- Custom CSS design system using a heritage Rajasthan palette (`#F6F1E8`, `#B99A62`, `#211E1A`, `#D8C5A6`, `#E8DFD1`, `#FFFFFF`) with `Cormorant Garamond` and `DM Sans` typography
- Responsive `<picture>` media delivery in AVIF, WebP, and JPEG

## Key Features

- Dedicated desktop and mobile architectural hero framing using authentic Hotel Rajmahal photography
- Scroll-responsive transparent-to-ivory navigation with mobile drawer
- Rooms & Suites showcase (Double Room, Deluxe Room, Family Room, Junior Suite, Maharaja Suite) with direct WhatsApp tariff enquiries
- 11 verified property amenities and Times Rajmahal Restaurant dining showcase
- Filterable photographic gallery with full-screen keyboard-accessible lightbox
- Explore Nathdwara destination guide with verified distances to nearby landmarks
- Validated 9-field WhatsApp reservation enquiry form redirecting to `+91 92576 76733`
- Click-to-call phone links, Google Maps embed, and `Hotel` / `LocalBusiness` JSON-LD structured data

## Local Development

